# Анализ внешних зависимостей проекта
## Входные данные
### Проанализируй следующие файлы:
- `./package.json` — прямые зависимости проекта (dependencies и devDependencies).
- `./plans/dependency.json` — полное дерево зависимостей, результат команды `npm ls --long --json > dependency.json` (содержит транзитивные зависимости).
- `./angular.json` — конфигурация Angular CLI, может содержать ссылки на дополнительные пакеты (builders, schematics и т. д.).

# Задача
Построить исчерпывающий список всех библиотек, используемых в проекте, включая транзитивные зависимости, с указанием текущих и максимально доступных совместимых версий.

# Требования к списку
- В список включи все библиотеки — как прямые зависимости из package.json, так и транзитивные (подтянутые другими пакетами).
- Поле `version NEW` заполни максимально возможной версией, совместимой с остальными библиотеками в проекте. Если обновление невозможно или нежелательно — укажи причину в комментарии.
- Учти совместимость между библиотеками по версиям: если обновление одной библиотеки требует обновления другой, отметь это в комментарии.
- Если библиотека больше не поддерживается, устарела или имеет критический баг — укажи это в комментарии с пояснением и, при возможности, предложи альтернативу.
- Для транзитивных зависимостей в поле dependency укажи, какой пакет подтянул эту зависимость.
- Для каждой библиотеки укажи точный URL репозитория, откуда можно скачать пакет (например, `https://registry.npmjs.org/@angular/platform-browser/-/platform-browser-22.1.4.tgz` или ссылка на `npm registry`).
- В поле alternative укажи команду для установки через npm (например, npm install package@version).
- Формат результата — `CSV` со столбцами

# Столбец	Описание
- `name`	Название библиотеки
- `version OLD`	Текущая установленная версия
- `version NEW`	Максимально доступная совместимая версия
- `URL к репозиторию`	Ссылка на репозиторий пакета (GitHub, GitLab, npm)
- `alternative`	Команда npm для установки или обновления
- `dependency`	Для транзитивных зависимостей — имя пакета, который подтянул эту зависимость. Для прямых — пусто или direct
- `комментарий`	Заметки о совместимости, рисках, устаревании и т. п.

# Дополнительные условия
- Разделитель в `CSV` — точка с запятой (;).
- Кодировка файла — `UTF-8`.
- Результат сохрани в файл `./plans/external-deps.csv`.
- Группируй строки: сначала прямые зависимости, затем транзитивные (в алфавитном порядке внутри каждой группы).
